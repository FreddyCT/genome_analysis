# genome_analysis
Pipeline for re-analysis of core methods in Paper 1 Zhang et al. 2017<br>

```
Covers:
- Genome assembly of *E. faecium* E745 (PacBio long-reads)
- Assembly evaluation + annotation
- Synteny comparision
- Trimming
- RNA-Seq DE between serum and BHI medium
```
